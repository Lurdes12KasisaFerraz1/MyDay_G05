# MyDay_G05

**MyDay** é um diário de aprendizagem para estudantes universitários. Todos os dias o estudante regista o que aprendeu (texto, fotografias, vídeo ou áudio), guarda o local onde estudou e associa o registo a uma disciplina e a um projeto. Cada registo pode ser privado, só para amigos ou público.

Projeto do grupo **G05** — IADE.

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `00_Identificacao/` | Identificação do grupo e do projeto (`info.md`) |
| `01_Memoria_Descritiva/` | Memória descritiva do projeto (`memoria.md`) |
| `02_Imagens/` | Capturas dos ecrãs da aplicação |
| `03_Videos/` | Vídeo de demonstração e vídeo de apresentação |
| `04_Documentacao_Tecnica/` | Arquitetura MVC, modelos de dados e navegação |
| `05_Artefactos/` | Código-fonte da aplicação Flutter (`myday_app/`) |
| `06_Dados_Investigacao/` | Dados recolhidos na investigação com utilizadores |
| `07_Autorizacoes/` | Autorizações e consentimentos |

## Aplicação

A aplicação está em `05_Artefactos/myday_app/` e foi desenvolvida em **Flutter (Dart)** com arquitetura **MVC (Model-View-Controller)**. As instruções para a executar estão no README dessa pasta.
